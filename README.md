# Nemorphic Reimagined

Rediseña la web del sello techno Nemorphic a partir de los archivos adjuntos. Entrega exactamente tres archivos independientes: index.html, style.css y main.js. Conserva todos los textos y rutas Assets/...; preserva sin cambios funcionales la lógica de renderizado dinámico de artistas y iframes de SoundCloud. El hero debe mantenerse visualmente idéntico a la referencia: Assets/inicio.png con ondas sutiles, logo central Assets/logo nemorphic.png, título “Bienvenidos a Nemorphic” y eslogan “Más que groove, cultura.”. Inspírate en Logo Nemorphic.png para una estética underground minimalista, elegante y premium. Usa DM Serif Display en títulos y sans moderna en cuerpos, reemplaza iconos sociales antiguos por SVG/vectoriales con hover profesional. Incluye el código completo, sin placeholders.
